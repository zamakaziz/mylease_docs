## 1. Problem Summary & Objectives

### 1.1 The Bug Reported
When an approval form was generated by clicking **"Generate Approval Form"** for Audit `806` (Year `2024`), it became unconditionally available for download in the approval creation form (`+ New Approval Request` drawer) regardless of whether the user was viewing a different audit (such as `807`) or selecting a different year (e.g. `2025`).

### 1.2 Core Requirements
1. **Strict Audit & Year Isolation**:
   - If an approval form is created for `audit_id: 806` and `year: 2024`, it must **only** be available for Audit `806` under Year `2024`.
   - It must **not** be available for other audit IDs (e.g., `807`).
   - It must **not** be available for other audit years of the same audit (e.g., `2025`).
2. **Dynamic UI Drawer Feedback**:
   - In the `+ New Approval Request` drawer:
     - If the form has been generated for the current `audit_id` and selected year(s), display the **"Download Approval Form"** button.
     - If the form has **not** yet been generated for that specific `audit_id` and selected year(s), display **"Generate Approval Form ({year})"** instead of the download button.
3. **Document Cross-Contamination Fixes**:
   - Prevent documents from other audits, locations, or historical years from leaking into the generated approval PDF summary.
4. **Approve / Reject Notifications**:
   - When an approver approves or rejects an approval request, send an email notification (`ApprovalStatusMail`) and create an in-app bell notification (`AuditWindowNotifications` broadcast via `DashboardEvent`) for the requester.

## 2. Root Cause Analysis

1. **Unconditional Button in UI (`ApprovalsTab.vue`)**:
   - The "Download Approval Form" button in the approval creation drawer was rendered unconditionally without checking if a form had actually been generated for that specific audit ID and year.
2. **Global Document Scope Leakage (`AuditDocument.php`)**:
   - `AuditDocument::scopeVisibleForAudit` fetched documents where `year = 'Common'` and document types were `Lease` or `Amendment` globally without filtering by `location_id`. This leaked over 1,000 documents from other client properties into Audit 807.
3. **Unfiltered Summary Queries (`ApprovalRequestSummaryService.php`)**:
   - `extractInformationReviewed` queried location documents without restricting to the active audit's year(s), pulling in historical statements from 2021, 2022, 2023, and 2025.
4. **Router Parameter Synchronization (`auditing.vue`)**:
   - The auditing page lacked a reactive watcher on `$route.query.id`, so navigating between `id=806` and `id=807` did not re-fetch fresh audit data (`getAllData()`), causing the UI to retain the previous audit's state and years.

## 3. Implementation Details

### 3.1 Backend Architecture

#### 1. [`AuditDocument.php`](file:///home/c864/Projects/mylease/backend/app/Models/AuditDocument.php)
- Corrected `scopeVisibleForAudit` to ensure that `year = 'Common'` documents and location-level agreements/amendments are strictly filtered by `$audit->location_id`.
```php
public function scopeVisibleForAudit($query, Audit $audit, ?array $years = null)
{
    $locationId = $audit->location_id;

    return $query->where(function ($q) use ($audit, $locationId, $years) {
        $q->where('audit_id', $audit->id);

        if ($locationId) {
            $q->orWhere(function ($locQ) use ($locationId, $years) {
                $locQ->where('location_id', $locationId)
                     ->where(function ($sub) use ($years) {
                         $sub->whereNull('year')
                             ->orWhere('year', '')
                             ->orWhere('year', 'Common');
                         if (!empty($years)) {
                             $sub->orWhereIn('year', $years);
                         }
                     });
            });
        }
    });
}
```

#### 2. [`ApprovalRequestSummaryService.php`](file:///home/c864/Projects/mylease/backend/app/Services/Approval/ApprovalRequestSummaryService.php)
- Constrained `extractInformationReviewed` to only select statements and reconciliations for the audit's location that match `$years` (or Common/blank year).
- Constrained `extractConcessions` to pass `$years` into `visibleForAudit`.

#### 3. [`ApprovalController.php`](file:///home/c864/Projects/mylease/backend/app/Http/Controllers/API/ApprovalController.php)
- **`previewPdf()`**:
  - Validates requested years against the audit's allowed years.
  - Generates the preview PDF.
  - Caches generation status under `approval_form_status_{$auditId}_{$yearKey}`.
  - Persists preview PDF to local storage: `approval_forms/audit_{$auditId}_year_{$yearKey}_preview.pdf`.
- **`getApprovalFormStatus()`**:
  - New API endpoint `GET /api/audits/{auditId}/approval-form-status?selected_years=...`
  - Returns `{ status: true, is_generated: boolean, audit_id: int, audit_year: string, data: object }`.
- **`store()`**:
  - Saves `'audit_year' => $audit->audit_year ?? null` when creating an approval request.
- **`index()`**:
  - Supports filtering approval listings by `audit_year`.

#### 4. [`routes/api.php`](file:///home/c864/Projects/mylease/backend/routes/api.php)
- Registered route:
```php
Route::get('audits/{auditId}/approval-form-status', [ApprovalController::class, 'getApprovalFormStatus']);
```

### 3.2 Frontend Architecture

#### 1. [`auditing.vue`](file:///home/c864/Projects/mylease/frontend/pages/auditing.vue)
- Added route synchronization in `beforeRouteUpdate` and a watcher for `'$route.query.id'`:
```javascript
beforeRouteUpdate(to, from, next) {
  next()
  if (to.query && to.query.id && String(to.query.id) !== String(this.audit_id)) {
    this.audit_id = to.query.id
    this.getAllData()
  }
  // ... discussion param handling
},
watch: {
  '$route.query.id'(newId, oldId) {
    if (newId && String(newId) !== String(oldId) && String(newId) !== String(this.audit_id)) {
      this.audit_id = newId
      this.getAllData()
    }
  },
  // ...
}
```

#### 2. [`ApprovalsTab.vue`](file:///home/c864/Projects/mylease/frontend/components/auditing/ApprovalsTab.vue)
- **Reactive State & Cache**:
  - Added `approvalFormStatusMap` in `data()` to track generation status for each `${auditId}_${currentFormYearKey}`.
  - Added computed properties `currentFormYearKey` and `isApprovalFormGeneratedForCurrentAuditAndYear`.
- **Drawer Button Rendering**:
  ```html
  <!-- Download Approval Form: ONLY shown when generated for current audit and year -->
  <el-button
    v-if="isApprovalFormGeneratedForCurrentAuditAndYear"
    size="medium"
    type="text"
    style="color:#3949ab;font-weight:600;"
    :loading="isDownloadingForm"
    @click="downloadApprovalForm"
  >
    <i class="el-icon-download mr-1"></i>Download Approval Form
  </el-button>

  <!-- If NOT generated yet for this audit and year, show Generate button -->
  <el-button
    v-else
    size="medium"
    type="text"
    style="color:#e6a23c;font-weight:600;"
    :loading="isGeneratingPreviewPdf"
    @click="generateApprovalForm"
  >
    <i class="el-icon-document mr-1"></i>Generate Approval Form ({{ currentFormYearKey }})
  </el-button>
  ```
- **Watchers**:
  - `auditId`: When switched, calls `resetNewApprovalForm()`, clears stale status, and runs `checkApprovalFormStatus()`.
  - `newApprovalForm.selected_years`: When year selection changes, queries `checkApprovalFormStatus()`.
- **Generation & Download**:
  - `generateApprovalForm()` updates backend cache and local status upon success.
  - `downloadApprovalForm()` generates download filename with audit ID and year suffix (`Approval_Form_Audit_{auditId}_{yearKey}.pdf`).
